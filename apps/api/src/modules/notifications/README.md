Minimal tenant-aware dispatch mechanism: `POST /notifications` writes a tenant-scoped `Notification` row and enqueues a BullMQ job (tenantId + notificationId only) onto the `notifications` queue; `apps/worker`'s `NotificationsProcessor` rebuilds a tenant-scoped Prisma client from the job's tenantId and delivers it. Templates, broadcast lists, and real email/SMS provider integrations are still Phase 8+ (Integrations) — this module only proves the queue/tenant-isolation plumbing end to end.
